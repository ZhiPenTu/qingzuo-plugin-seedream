# Seedream 图像设计插件 (@commerce/plugin-seedream)

轻作官方独立插件，基于火山方舟 **Seedream 5.0 Pro** 多模态图像生成大模型，为电商视觉与商品设计提供高画质生成与编辑能力。

## 功能特性

- **文生图设计**：输入详尽的风格、主体、材质与光影提示词，生成 2K 超清商品与场景设计图。
- **多模态参考生图**：上传参考图片进行风格延续、主体编辑或垫图重绘。
- **分辨率与格式**：支持 2K、1K 以及 1:1 分辨率，支持 PNG (无损/透明) 与 JPEG 格式输出。
- **凭据隔离**：火山方舟 API Key 安全保存在宿主凭据库，避免明文泄露。
- **离线安全**：基于轻作沙箱环境与受控网络通道，支持生成图片在线预览与导出保存。

## 开发与打包

```sh
npm install --ignore-scripts
npm test
npm run pack
```

打包生成的 `.ecplugin` 文件可在轻作桌面端的「插件管理」中直接导入使用。
